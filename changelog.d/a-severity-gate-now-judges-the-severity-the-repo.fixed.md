- **A severity gate now judges the severity the report prints for the finding.** `--fail-on critical|high|medium|low`, `config.gate.failOn`, per-control thresholds and `--fail-on-new` read it after the control's severity floor, KEV, EPSS and reachability. Verdicts change both ways: a high on KEV now fails `--fail-on critical`, and an unreachable critical now passes it.
