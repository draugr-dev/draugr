- **Trivy no longer looks up a `pom.xml`'s dependencies in Maven Central.** Every Trivy run passes `--offline-scan`. A pom whose transitive dependencies are not in the local Maven repository is listed under `unread-files`. Run `mvn dependency:resolve` before scanning, or set `config.controls.sca.trivyFs.resolveMaven: true`, which declares the `disclosure` effect.
