- **A descriptor that sets `config.exclude[].acceptedBy` is refused.** `draugr validate` and `draugr scan` name the key and say to delete the line. Who wrote an exclusion is its line's git history, which `report.json` carries in `descriptor.exclusions[].gitHistory`. `report.json`, `results.sarif` and the MCP `accepted` list no longer carry `unverifiedAcceptedBy`, and `draugr diff` still reads an earlier baseline that does.
