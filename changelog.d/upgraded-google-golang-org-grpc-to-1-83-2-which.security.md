Upgraded `google.golang.org/grpc` to 1.83.2, which fixes CVE-2026-84445: a gRPC-Go xDS server could be crashed by a request missing its `:authority` and `Host` headers. It reaches Draugr as an indirect dependency of the OpenTelemetry OTLP exporter, and Draugr runs no xDS server, so nothing here was exploitable; the dependency is upgraded because a known-vulnerable version in the tree is a finding Draugr would report on anybody else.
