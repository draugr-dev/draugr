**`publishes` — the identifier the outside world knows a project by.** A package URL, an image reference or a URI: what a consumer's own bill of materials calls the thing you ship, as against `project`, which is what you call it. A generated VEX document uses it as its product, so a statement is matched by the identifier a consumer actually holds rather than by a `pkg:generic/` string synthesized from your descriptor — one that nothing matches is read, understood, and applied to nothing, with no error on either side. Leave the version out and `release.version` is appended, so the identifier moves when the release does.
