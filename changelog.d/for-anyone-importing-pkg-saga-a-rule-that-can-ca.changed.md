For anyone importing `pkg/saga`: a rule that can carry a reason is now a `Reasoned[T]` rather than a bare string, so `component.Exposure` reads as `component.Exposure.Value`. `saga.Unstated(v)` builds one with no reason attached. This affects `Component.Exposure`, `Component.Criticality`, `GateConfig.FailOnPriority` and `GateConfig.Controls`; descriptors are unaffected, and one written before the long form existed still serializes to exactly the bytes it did.
